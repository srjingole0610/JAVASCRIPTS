Introduction to the For Loop

In JavaScript, the for loop is used to execute a block of code repeatedly for a specified number of times. It’s ideal for iterating over arrays or performing tasks a known number of times. The syntax is: 

for (initialization; condition; increment) {
  // Code to execute in each iteration
}

- Initialization: Executes once before the loop starts (e.g., let i = 0). - Condition: Evaluated before each iteration; if true, the loop continues (e.g., i < 5). - Increment: Executes after each iteration (e.g., i++).

Iterating Over Arrays

The for loop is commonly used to iterate over arrays by accessing elements via their indices. The loop’s condition often uses the array’s length property to determine the number of iterations.

Example: 

const arr = ["Apple", "Banana", "Orange"];
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}

Control Statements: break and continue

The break statement exits the loop entirely, while continue skips the current iteration and proceeds to the next. These are useful for controlling loop behavior based on conditions.

Example: 

for (let i = 1; i <= 5; i++) {
  if (i === 3) continue; // Skip 3
  if (i === 5) break; // Exit at 5
}

Nested For Loops and Best Practices

Nested for loops involve a loop inside another loop, often used for multi-dimensional arrays or complex iterations. However, excessive nesting can harm performance and readability.

Best Practices:

  • Keep loops simple and avoid deep nesting.
  • Use descriptive variable names (e.g., index instead of i).
  • Consider forEach or for...of for array iteration in modern JavaScript.
  • Ensure the condition prevents infinite loops.
